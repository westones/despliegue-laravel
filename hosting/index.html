Sobre el proyecto

Aplicación Laravel con Vite y Tailwind CSS. Firebase Hosting sirve la parte estática; la lógica PHP se ejecuta en el servidor del proyecto.

Backend

Laravel 13 sobre PHP 8.5, con rutas y vistas Blade.

Frontend

Vite + Tailwind CSS 4 para los estilos y los assets compilados.

Despliegue manual con Firebase CLI y automatización con GitHub Actions.
